# Data

| Path | What it is |
|---|---|
| `sample/demo_ohlcv.csv` | **Synthetic** daily OHLCV, 252 business days from 2020-01-02, generated by `tools/generate_sample_data.py` with seed 42 (Week 1 single-ticker exercises). Not a real security. |
| `sample/multi_ticker_ohlcv.csv` | **Synthetic** 3-ticker panel (DEMO/ORNG/BANK) in `yfinance` multi-download format (two header rows), generated by `tools/build_day02_notebook.py`. BANK starts 2020-04-01, so leading rows are empty on purpose (Day 02). |
| `sample/long_spy_like.csv` | **Synthetic** ~10-year daily OHLCV (2,520 business days, 2015-01-02..2024-08-29), generated by `tools/generate_sample_data.py` with seed 808 for Week-2 SMA50/100/200 crossover backtests (Days 08–11). |
| *(in-notebook)* Day 12 & Day 13 | Day 12 embeds deterministic canned Alpha-Vantage & row-records JSON payloads; Day 13 generates an unseen ~10-year synthetic ticker (`UNSEEN`) in its setup cell so capstone evaluation cannot rely on memorised `df_long` behaviour. |
| `processed/` | Outputs your notebooks generate (e.g. cleaned closes, Milestone reports, Capstone results). Git-ignored. |

Live downloads (e.g. `SPY` via `yfinance` on Day 01, or Alpha Vantage on Day 12)
are *optional and ungraded*: real feeds change format, rate-limit, and require
API keys — which is itself a core lesson of Days 01 and 12, and why no grade
ever depends on a network call.
