# Data

| Path | What it is |
|---|---|
| `sample/demo_ohlcv.csv` | **Synthetic** daily OHLCV, 252 business days from 2020-01-02, generated by `tools/generate_sample_data.py` with seed 42. It is not a real security. It exists so assessed work is deterministic and offline. |
| `processed/` | Outputs your notebooks generate (e.g. Day 01's cleaned close prices). Git-ignored. |

Live downloads (e.g. `SPY` via `yfinance`) are an *optional, ungraded* part of
Day 01: real feeds change format, rate-limit, and disappear — which is itself a
lesson of Day 01 and the reason no grade depends on a network call.
