# journal/<YYYY-MM-DD>.md

**Built:** what shipped today, even if ugly
**Broke:** the first thing that failed, and the error message
**Numbers:** one measured number, with units and sample size
**How I might be fooling myself:** the assumption you did not test
**Tomorrow:** the single next action

## Rules

1. Five fields, two minutes. A perfect entry tomorrow beats a bloated one today.
2. Date the file by the day it happened. Backfill gaps, dated correctly, and say so.
3. Numbers must be numbers: "Sharpe 0.8 on 340 OOS bars" beats "it did well".
4. The fooling-myself line is the highest-value line in the course. Never leave it empty.
