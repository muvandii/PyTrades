# D12 — Replication R1: Time-Series Momentum

## Objective

Implement Moskowitz-Ooi-Pedersen (2012) on your data, and reconcile your numbers against the paper's claims with every gap traced to a named deviation.

## Teaches

Reading a paper is an implementation task; the paper's numbers are an input, not an answer. A replication that "did not match" is a result once the deviation is named - and a fiction until it is.

## Build

1. **`papers/R1_tsmom/impl.py`** — the TSMOM rule on a multi-asset universe:
   - signal: `sign(P_t / P_{t-12} − 1)` per asset, monthly rebalance;
   - optional vol scaling: `target_vol / σ_t` with a causal (trailing) σ estimate and a cap;
   - all results net of costs; the config committed alongside.
2. **`papers/R1_tsmom/comparison.md`** — your numbers vs the paper's, side by side, with a named deviation per gap.

   | Row | Paper | Yours | Deviation |
   | --- | --- | --- | --- |
   | Sharpe | | | |
   | Vol | | | |
   | Max DD | | | |
   | Turnover | | | |
   | Sample | | | |

3. **`papers/R1_tsmom/deviations.md`** from `shared/templates/deviation-log.md`, one row per deviation with direction and approximate size.

## Required experiments

## Definition of done

- [ ] `impl.py`, `comparison.md`, `deviations.md` all exist and are committed
- [ ] Every gap in the comparison table has a named deviation

- [ ] The strategy appears in `strategies/index.md` with a verdict word

## Deviation taxonomy (use these names)

| Class | Meaning | Typical size |
| --- | --- | --- |
| universe | different assets than the paper | large for TSMOM (futures → ETFs) |
| period | different sample | large; TSMOM's reputation leans on 2008-2014 |
| costs | different fee/slippage assumptions | moderate, always negative |
| sizing | cap, target vol, no-leverage differences | moderate and usually flattering |
| data-frequency | monthly vs daily rebalance | small for returns, large for costs |
| excess-return-definition | cash/collateral treatment | small here, large in futures |
