# D17 — 30-day live log + reconciliation + post-mortem

## Objective

Explain every basis point of the gap between live paper PnL and the backtest's promise, and finish milestone M5 with a report a stranger could audit.

## Teaches

Live PnL diverges from backtest PnL in explainable, budgetable ways. A divergence you can name is a cost of doing business; a divergence you cannot name is a bug you have not found yet - or a strategy you do not understand.

## Build

1. **`live/equity.csv`**: 30+ rows, one per trading day, no unaccounted gaps.
2. **Shadow backtest**: the same spec re-run *as of* each live day (rolling), not a single run over the window - the live bot decided each day with only the data available then.
3. **`live/reconciliation.md`** from `shared/templates/reconciliation.md`:

   | Component | Live | Backtest | Gap | Cause |
   | --- | --- | --- | --- | --- |
   | Fees | | | | |
   | Slippage | | | | |
   | Timing (decision → fill) | | | | |
   | Missed / rejected fills | | | | |
   | Sizing differences | | | | |
   | Regime | | | | |
   | Unexplained | | | | |

4. **`live/postmortem.md`**: every operational failure with timestamp and consequence; every mid-run intervention logged as a killed variant; what you would change ranked by expected bps; and the **expected-divergence budget** for next month.

## Required numbers

- [ ] Total live vs backtest return over the window, and the gap as a percentage of the backtest's
- [ ] The gap decomposed into the components above, summing to the total (within rounding)
- [ ] Unexplained bucket explicitly quantified, even if above 10%
- [ ] Realised volatility of the live window vs the backtest's median (the regime check)
- [ ] Expected-divergence budget: X bps/month, of which Y structural and Z to watch

## Definition of done

- [ ] 30+ equity rows; a log file per day including no-trade days
- [ ] Ten spot-checked days where the shadow backtest reproduces the live decisions exactly
- [ ] Reconciliation attributes ≥ 90% of the gap to named components, or states why it cannot
- [ ] Post-mortem includes the expected-divergence budget
- [ ] M5 checklist from `week-12.md` fully ticked
- [ ] The traded strategy's fingerprints match the ones in the backtest artifacts
