# Phase 7 — Synthesis (Week 13)

**Milestone:** [M6 Capstone](milestones/M6-capstone.md) — public writeup + portfolio + repo shipped; a stranger can clone the repo and understand everything.

## What this week is

Not a summary. Compression. Thirteen weeks of work become four artifacts a stranger can check:

| Artifact | Reader's question it answers |
| --- | --- |
| `README.md` | can I run this in fifteen minutes? |
| `WRITEUP.md` | what did you find, and what are you not claiming? |
| `PORTFOLIO.md` | what would you actually trade, and why each line? |
| `graveyard.md` | what did the market teach you, ranked? |

## The two tests

1. **Stranger-clone test** (the milestone's heart): fresh clone → README only → reproduced
   tearsheet in 15 minutes, matching the writeup's headline number. Every friction is a bug in
   the docs, fixed before the pass is certified.
2. **Recall test** ([capstone/recall-test.md](../../capstone/recall-test.md)): three concepts
   explained from memory, one coded from scratch in an empty file.

## The honest ending

Every student who finishes this course has a public repository that contains failures. That is the
point: the graveyard taxonomy is the most valuable artifact because it is the compressed result of
every hypothesis the market rejected for you, and the writeup's "honest limitation" paragraph is
what makes the surviving claims believable. The course ends with a portfolio you can defend, a
process you can repeat, and a roadmap you wrote yourself - which is exactly the state the whole
thing was designed to reach.
