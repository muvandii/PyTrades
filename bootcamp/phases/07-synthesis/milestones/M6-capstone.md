# M6 — Capstone (end of Week 13)

## Pass condition

> Public writeup + portfolio + repo shipped; a stranger can clone the repo and understand everything.

Verbatim from the course registry, operationalised by the Week 13 gate as the **stranger-clone
test** (fresh clone, 15 minutes, README-only, reproduced tearsheet matching the writeup's headline
number) plus the **recall test** (three concepts explained from memory, one coded from scratch in
an empty file).

## What it proves

That the quarter produced something transferable. Anyone can hold backtest numbers in their own
head; the capstone is the proof that yours are checkable by someone who has never met you - and
that you can reproduce and explain the machinery without the course's files in front of you.

## Supporting requirements

- `README.md`: two-sentence description, 4-command quickstart verified on a fresh clone, artifact map, data limitations, documented stranger-clone pass
- `WRITEUP.md`: question → method → three best artifacts → three instructive deaths → honest limitation → next experiments, with a public link
- `PORTFOLIO.md`: lines, weights, sizing/risk rules, evidence per line, removal criteria, live status
- `graveyard.md`: 3-5 ranked causes with counts, shares, predictive signals, entries retained
- 15+ verdicts, 80+ journal entries, Phase 7 retro written

## Fail path

| Symptom | Diagnosis | Fix |
| --- | --- | --- |
| quickstart needs undocumented steps | the repo has no real entry point | run the quickstart in a fresh clone and write down every command you actually typed; put exactly those in the README |
| writeup quotes a number the repo cannot reproduce | the headline came from memory or a notebook | re-run the artifact, quote the reproduced number, and keep the run's `meta.json` next to it |
| graveyard is a list, not a taxonomy | the clustering step was skipped | group by cause, count, rank, and write the predictive signal for each cause |
| portfolio doc is aspirational | lines that no verdict supports | cut every line without an evidence link; the document is a claim about your work, not your hopes |
| recall test deferred "until later" | the course's last gate is uncomfortable for a reason | do three concepts now; codify one in an empty file; write the two-sentence reflection |

## Remediate after Week 13 (the course's real ending)

M6 is the end of the *course*, not of the work. If M5 is still in progress, finish the window and
append the reconciliation. If a strategy still deserves a verdict, write it as a post-course entry
in the graveyard or registry - the repo stays alive, and the roadmap in `PORTFOLIO.md` is the list
of experiments your next quarter starts from. The single best signal that the course worked: you
already know what you would test next, and you know what would make you kill it.
