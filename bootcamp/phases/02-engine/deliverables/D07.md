# D07 — Walk-forward/OOS runner + tearsheets + look-ahead suite green

## Objective

Make out-of-sample evaluation and tearsheet generation automatic, so that any idea can go from raw data to a defensible verdict in under 30 minutes - and prove the engine cannot see the future.

## Teaches

Out-of-sample is a process, not a number you compute once. It is a splitter, a parameter policy, an embargo, a report that shows both windows, and a habit of reporting the pooled OOS result instead of the best window.

## Build

1. **`engine/walkforward.py`** per [spec/walkforward-splitter.md](../spec/walkforward-splitter.md):
   - `splits(index, train_bars, test_bars, mode, embargo_bars)`
   - a runner that optimises on train, evaluates on test, and concatenates the test windows
   - outputs `reports/walkforward/<strategy>.csv` with per-split rows and a summary line
2. **`engine/tearsheet.py`** generating markdown per `shared/templates/tearsheet.md`, including the IS-vs-OOS table and the "what this does not tell you" paragraph.
3. **`tests/test_lookahead.py`** with the time-travel test and the signal-shift premium test.
4. **`reports/lookahead-audit.md`** with all four tests from [lookahead/lookahead-test-suite.md](../lookahead/lookahead-test-suite.md), including the blind-data paragraph.
5. **A strategy tearsheet** for one real strategy: `strategies/<id>/tearsheet.md` with IS and OOS columns populated.

## Definition of done

- [ ] `engine/walkforward.py` produces the split CSV with per-split IS and OOS Sharpe
- [ ] The pooled OOS result is computed and stated (not the best split)
- [ ] `engine/tearsheet.py` regenerates a tearsheet with one command
- [ ] `tests/test_lookahead.py` passes; contract suite green against `engine.backtest`
- [ ] `strategies/<id>/tearsheet.md` shows IS vs OOS columns and a degradation ratio
- [ ] **M2 timed run**: a fresh idea taken data → tearsheet → verdict in under 30 minutes, with the timer log
- [ ] `engine/README.md` updated: new modules, new behaviours, and the single place the timeline is shifted
