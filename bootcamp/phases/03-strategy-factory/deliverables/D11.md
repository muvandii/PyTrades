# D11 — Overfitting audit + parameter sensitivity heatmaps

## Objective

Attack your own best result with every tool the course has given you, and publish the audit whether it destroys the strategy or not.

## Teaches

If the edge only exists at one parameter value, the edge is in your search, not in the market. Overfitting is not a moral failing; it is the default outcome of research, and the only defence is a mirror you are willing to look into.

## Build

1. **Heatmaps**: two-parameter grids for at least two strategies (e.g. MA fast/slow; Bollinger window/z; momentum lookback/hold), saved as `reports/sensitivity/<id>.csv` with a markdown summary of the surface shape.
2. **`reports/overfitting-audit.md`** covering your best strategy, with these required sections:

   | Question | Your answer |
   | --- | --- |
   | How many specifications were tested before this one? | |
   | OOS/IS Sharpe ratio | |
   | Plateau width in parameter units (and stability across the grid) | |
   | Does it survive 2× cost assumption? | |
   | Does it survive dropping its best year? Its best 5% of trades? | |
   | Number of independent bets, and the t-stat they support | |
   | What would make you abandon it? (kill criteria in observable terms) | |

3. **Deflation sentence**: write one honest sentence estimating how much of the headline Sharpe is selection, and put it in the verdict file too.
4. **Second universe check**: re-run the survivor on a related universe (or a different 10-year window). Report what changed.

## Definition of done

- [ ] Two-parameter grids saved for 2+ strategies with a surface-shape classification
- [ ] `reports/overfitting-audit.md` answers all seven questions
- [ ] The deflation sentence appears in both the audit and the survivor's verdict
- [ ] At least one fragility test actually changed your verdict word or your confidence (or you document that none did)

## Evidence

`reports/overfitting-audit.md` · `reports/sensitivity/*.csv` · the updated verdict(s)
