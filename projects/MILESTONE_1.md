# 🏁 Milestone 1 — Data Handler (end of Day 04)

**Scope:** everything Days 01–04 built: intake, validation, persistence,
segregation, rebasing, resampling, first risk numbers.

## Gate criteria (all must hold)

1. **Notebooks 01–04:** Section G fully green *each*, after Kernel → Restart & Run All,
   on a clean checkout (bundled data only — no hand-placed files).
2. **Function inventory** exists (Day 04, Section F ✍️): every reusable function,
   grouped *data-in* (load/validate/save/slice) vs *analytics* (normalise/resample/volatility).
3. **No function you wrote** mutates its caller's data, uses globals, or prints instead of returning.
   (Be ready to be asked "how would a test prove that?" for any of them.)
4. **Self-review filed:** two least-trusted functions named with reasons; one concrete
   refactor queued for Day 10; unresolved questions listed.
5. **Artifacts reproducible:** `data/processed/day01_close.csv`,
   `day02_close_panel.csv`, `day03_normalised.csv`, `day04_monthly_close.csv`
   can each be regenerated by re-running their notebook's Section F.

## Review prompts (used when you report back)

  containing a `0.0` tick — which Day 01 check was supposed to catch that upstream?
